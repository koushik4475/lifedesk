# Contributing

1. Fork the repository and create a focused branch.
2. Install dependencies with `npm install`.
3. Keep business logic outside UI components where practical; validate untrusted input.
4. Add tests for date, recurrence, money and persistence behavior.
5. Run `npm run lint`, `npm run typecheck`, `npm test` and `npm run build`.
6. Open a pull request with a clear summary, screenshots for UI changes and test results.

Do not commit personal data, exported backups, credentials, `.env` files or generated build output.
